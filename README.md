# Dashboard zakázek — nábytek na míru

Veřejný přehled zakázek nábytku na míru: **https://make-more-s-r-o.github.io/nabytek-dashboard/**

- `index.html` je stránka vygenerovaná ze soukromého repa firmy. Ručně se neupravuje, publikace ji přepisuje.
- `zakazky/` jsou **příspěvky kolegů**: každá zakázka má vlastní složku a stránka je načte sama.
- Postup, jak přidat zakázku, pole, obrázky i export 3D modelu z Blenderu jsou v **[AGENTS.md](AGENTS.md)**
  (stejný text je v `CLAUDE.md` pro Claude Code). Před pushem spusť `python3 tools/zkontroluj.py`.

Repo je veřejné: žádné kontakty ani adresy klientů, fotky jejich interiérů, nákupní ceny a slevy, ani tajné klíče.
